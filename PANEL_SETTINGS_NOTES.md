# Panel-Struktur Update

Dieses Update verschiebt allgemeine Channel-/Rollen-Einstellungen aus `/settings panel` in die jeweiligen Fach-Panels.

## Neue Regel

- `/settings panel` = nur allgemeine Bot-Verwaltung, Module, Export, Übersicht
- `/translate panel` = Quellkanäle, Zielkanal, Provider, Webhook/Bot-Verhalten
- `/welcome panel` = Welcome-/Leave-Channel und Texte
- `/rules panel` = Hausordnung-Channel, Gast-Rolle, Hausordnungstext
- `/memberlog panel` = Memberlog-Channel, Tracked-Rollen, Cleanup
- `/autoclear panel` = AutoClear-Channel, Ziel-Bot, Regeln, Zeitplan
- `/channel-clear panel` = manuelles Löschen von normalen Textkanälen

Dadurch müssen keine Channel-IDs mehr manuell in `/settings panel` eingetragen werden.
